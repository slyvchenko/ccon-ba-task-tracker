# v2.50.3: персональний фокус, пріоритетні виміри та повернення клавіатурного фокусу

**Scope:** FOCUS-07, FOCUS-08, PRIOR-05. Звичайна сторінка та поточні секції збережені. Усі три вимоги **PARTIAL** до приватного BA/Windows/NVDA приймання.

## Фокус без зміни офіційної черги

У наявному згорнутому блоці «Пріоритет і орієнтовний обсяг» можна натиснути «Закріпити мій фокус у цій групі» або «Скинути мій фокус». У рядку задачі з'являється невелика позначка «Фокус». Вкладка зберігає лише неприватний ключ задачі `CCON-123` у `sessionStorage`; Jira, SQLite, інші вкладки та серверний ranking не змінюються.

Pin є **tie-breaker лише після hard sprint lane і WRITE/actionRank**. Навіть закріплена backlog-задача не потрапить вище підтвердженого активного спринту, а READY/REVIEW не обжене WRITE у тій самій lane. Втрата задачі зі snapshot або перехід у DONE скидає pin. Скидання вручну негайно відновлює стандартне сортування.

## Пояснення пріоритету без змішування з часом

У тій самій секції окремо відображаються вплив (0–25), терміновість (0–25), залежності (0–20), оцінка обсягу XS–XL (ручна або низьковпевнена гіпотеза), підтверджене блокування. Невідомі або застарілі фактори позначаються «не підтверджено», а не вигаданими балами. Це не новий speed score. Hard sprint/WRITE і наявна 0–100 логіка залишаються незмінними.

## Клавіатурний фокус

Після явного Save (не під час редагування), відкриття mailto після збереження, bulk-повтору або bulk-помилки фокус повертається на доступну дію. Закриття bulk-діалогу повертає фокус до кнопки, яка його відкрила. Автоматичне опитування й оновлення даних **не** викликають цей механізм. Зовнішнє надсилання листів не автоматизовано.

## Верифікація і відкриті умови

Node тести перевіряють пріоритетні lane/action, cache invalidation, reset, незалежні фактори, видимий focus fallback. Chromium E2E перевіряє збереження pin після reload, reset, відсутність зміни server score та фокус bulk retry. Немає тверджень про реальне BA acceptance >90%, NVDA/Edge, mailto-клієнт, 8h soak чи живі Jira сценарії. `human_acceptance=NOT_RECORDED`.
