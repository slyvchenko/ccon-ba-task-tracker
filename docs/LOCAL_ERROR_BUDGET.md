# Opt-in local error budget (v2.50.8)

Вимкнено за замовчуванням. Увімкнути тільки на власному комп'ютері:

```powershell
python server.py --local-error-budget --open
```

Після запуску відкрити `http://127.0.0.1:8765/local-error-budget`. Оновлювати лічильники вручну кнопкою. У cloud-режимі не підтримується навіть після opt-in.

**Що вимірюється:** кількість HTTP API-відповідей за останні 60 хвилин процесу, 4xx/5xx, умовна успішність щодо 5xx, бюджет 1% для цілі 99%, p95 часу до формування HTTP-статусу. Моніторинг `/api/health` і сам запит метрик не впливають на знаменник. До 10000 записів у пам'яті, далі результати позначаються неповними. Менше 100 вибірок також означає недостатню статистику.

**Що принципово не вимірюється:** відмова мережі до сервера, завершення процесу, повна доступність браузера, Jira/Kibana/CCON, семантична правильність BA. 4xx показано окремо, не як серверні 5xx. Це корисний локальний індикатор, а **не SLA**.

**Захист даних:** за замовчуванням збір вимкнено. Після явного `--local-error-budget` збираються **лише час монотонного годинника, числовий статус і округлена тривалість**, без URL, методів, тіл запитів, PNR, issue key, токенів, адрес клієнтів або журналів. Немає файлів метрик, cookies, localStorage, remote API, таймерів чи регулярного background polling. Рестарт очищає вибірку.

**OPS-04 PARTIAL:** незалежний браузерний і Windows human UAT, оцінка достатності помилок та операційної корисності ще відкриті; synthetic CI не дорівнює підтвердженню SLA.
