# CCON BA Desk: аудит надлишкового та дубльованого UI перед візуальним спрощенням

**Дата:** 25.10.2026. **Вхідний стан:** `main` v2.33, кодова інспекція `dashboard.html`, `assets/dashboard.mjs` (`renderList`, `renderDetail`, `briefingMarkup`, `sourceMarkup`, `priorityBreakdown`, `previousAnalysisMarkup`, `legacyMarkup`, `updateFormStatus`, `previewBulkEmails`), `assets/dashboard.css`, модулі evidence/actions/history/decisions. **Доказ:** статична інвентаризація реального коду, **не** відеозапис користувача, eye-tracking або продуктивність. Стан кандидатів нижче **HYPOTHESIS**, не підтверджений надлишок.

## Продуктова мета

Один BA має за **3–5 секунд** зрозуміти «яку задачу обрати / що зробити / який готовий матеріал передати / де зберегти». На простій задачі не примушувати скролити 8 блоків, на складній не втрачати право бачити повні факти, точні поля REST, ZIP, часову вісь, розбіжності та технічні деталі. **Не додавати Quick/Deep modes, другий dashboard, нові вкладки, прихований Jira write або автоматичне надсилання.** Початкова архітектура «черга ліворуч, поточна задача праворуч» зберігається.

### Безпечний алгоритм ухвалення рішення

- Для кожного кандидата зняти реальні **до** screen recordings на 5 архетипах: 2-хв READY, WRITE email із ZIP, WAIT decision, multi-city/NDC deep RCA та змінений Jira snapshot під час manual edit.
- Заміряти: **time to Next Action**, кількість конкурентних CTA above fold, кількість scroll/expands, хибний Copy/Send/DONE, час повернення до задачі, пропущені critical facts. Відео та Jira/PNR залишаються у приватному середовищі.
- A/B only one grouped PR; **не прибирати функціонал через схожі назви**. Відсутність використання лише в synthetic CI не підтверджує зайвість.
- Мінімальний DoD: немає false-ready, semantic regression, зміни rank/sprint/WRITE, втрати доказів, розриву CAS, прихованого ручного листа або зростання часу deep case. Результат змін має бути **візуально спокійніший**, але не функціонально бідніший.

**Статус:** це попередній аудит, backlog hypotheses. PR #34 додає браузерні E2E та цю документацію; **жоден з VIS-01..16 не реалізовано або не видалено**.
