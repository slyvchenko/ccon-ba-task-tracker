# Односторінкова статистика CCON BA Desk

**Локальний маршрут:** `http://127.0.0.1:8765/stats` (або звичайний налаштований порт). Посилання **Статистика** розміщено поряд із кнопкою листів на головній сторінці. Сторінка одразу показує одну зведену панель, без окремого режиму задач. Кнопка **Оновити** перечитує поточні локальні агрегати; автоматичного фонового опитування немає.

## Що рахують показники

**Робочі задачі:** у `ba_state.db` активними є лише ті, що присутні в останньому імпорті. `У роботі = active - manualStatus DONE`, а `Завершені локально` **не дорівнюють Jira Done**. Архівовані задачі не входять в активні. `Активний спринт` включає тільки `activeSprint=true` з `activeSprintStatus=VERIFIED`. Для незавершених задач є рівно одна наступна група WRITE / READY / DECIDE / REVIEW / WAIT / OTHER. Ручний WAIT перекриває запропонований AI сигнал, але не змінює дані Jira. Ручні статуси показані незалежним розподілом. Якщо імпорту немає, замість вигаданих нулів у картках стоїть тире.

**Продукт:** 129 вимог і категорії IMPLEMENTED/PARTIAL/GATE/DEFERRED читаються на кожен запит із `docs/BACKLOG_ACCEPTANCE_LEDGER.json`. Це *code-reported* статуси, не підтверджене приймання. `Code + test` означає тільки наявність навігаційних вказівників. Gold-кейси і зовнішні gates позначені `0 підтверджено цією сторінкою`, **не** `0 виконано у світі`. `releaseApproved=false` і `BLOCKED_INDEPENDENT_UAT` визначаються консервативним локальним release report. CI та відкриті PR навмисно **не імітуються як live**: є посилання на актуальний GitHub Actions та issue #50.

## Захист даних і межі

- GET `/api/stats` підлягає тим самим перевіркам localhost Host/cloud authorization, що решта read-only API. Повертає лише числа, фіксовані enum і дату імпорту. **Не повертає** Jira keys, summary, PNR, notes, листи, timestamps ручних дій, raw ZIP або credentials.
- Жодних мережевих трекерів, Google Fonts, CDN, зовнішніх скриптів. Оновлення сторінки лише через same-origin GET; ніяких POST/Jira/email дій.
- Робоча статистика є *моментальним зрізом*, не історичним трендом. Вона не вимірює якість BA і не є доказом правильності висновків AI.
- Локальний HTTP сервер треба перезапустити після отримання оновлених source files. **Сам merge у GitHub не оновлює запущений локальний застосунок.**

## Паралельні виправлення у цьому пакеті

- Для записів `BA-05` тепер є per-question `manualRevision`; HTTP POST без `expectedManualRevision` відхиляється 428, а застарілий запис 409 без витоку чужої відповіді. Ручні нотатки після 409 не перезавантажуються автоматично. AI sync не підвищує manualRevision. Прямий Python CLI для міграції тимчасово залишається сумісним без токена, але не захищений від послідовних stale редагувань.
- `private_gold_review.py` відхиляє `PASSED`, якщо proof, independent review, відсутність safety violations, якість чи вимірювання суперечать результату. Додає лише анонімні TTNA/TTSH p50/p95. **Жодний синтетичний або заповнений локальний JSON не розблоковує** реальний release signoff.

Тестові маршрути: `tests/test_project_stats.py`, `tests/stats.test.mjs`, `tests/test_question_manual_cas_http.py`, `tests/test_ba_questions.py`, `tests/test_private_gold_review.py`. Фактичний Windows/BA UAT залишити відкритим, доки незалежні докази не будуть зібрані в авторизованому приватному середовищі.
